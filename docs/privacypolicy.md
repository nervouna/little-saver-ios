# 小小存钱罐隐私说明

小小存钱罐尊重并尽量减少对个人数据的处理。应用不包含广告、用户行为分析 SDK，也不向开发者运营的服务器发送你的财务数据。

## 保存的数据

应用会保存你主动输入或生成的交易、分类、预算、周期交易和应用设置。这些数据首先保存在设备本地。

启用 iCloud 的设备会使用 Apple CloudKit 将 Core Data 数据镜像到你 Apple 账户的私人数据库。开发者无法查看该私人数据库。CloudKit 的账户、网络和数据处理受 Apple 的服务与隐私政策约束。

## 系统功能

- 通知：记账提醒由 iOS 在本地安排，不依赖远程推送服务端。
- 生物识别：应用锁只接收系统返回的验证结果，不读取或保存 Face ID 或 Touch ID 数据。
- Widget、Intent 与快捷指令：扩展通过 App Group 访问同一份本地数据，用于展示或执行你请求的功能。

## 导入、导出与外部链接

只有当你主动操作时，应用才会读取所选 CSV 文件或生成导出文件。导出后的文件由你选择的系统分享目标处理。

“源代码”和“GitHub Issues”会打开外部网站；这些网站按各自的隐私政策处理访问数据。

## 你的控制

你可以在应用设置中导出或清除数据，并在系统设置中管理通知、iCloud 和生物识别权限。关闭 iCloud 不会自动删除已保存到 CloudKit 的数据；相关数据管理由你的 Apple 账户设置控制。

## 开源说明

本项目是 Dime 的 fork，隐私说明已按小小存钱罐当前实现重写。若实现发生影响数据处理方式的变化，本说明也应同步更新。
